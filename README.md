# GTA 6 open data (GTA VI HOW)

Facts about Grand Theft Auto VI with a status label, sources and check date for each, plus unlock times by time zone, edition prices by region and review scores. A mirror of **[gtasix.how/data/](https://gtasix.how/data/)**, synced every 6 hours.

| File | What's in it |
|---|---|
| [`data/gta6-facts.json`](data/gta6-facts.json) | Every fact [GTA VI HOW](https://gtasix.how) publishes, with status (`confirmed`, `reported`, `rumour`), sources and the date it was last checked. Unknown values are `null`. |
| [`data/unlock-times.csv`](data/unlock-times.csv) | Launch unlock time per time zone, local and UTC, with the PlayStation Store and Xbox Store listing each one comes from. |
| [`data/prices.csv`](data/prices.csv) | Edition prices by region and currency. |
| [`data/gta6-reviews.csv`](data/gta6-reviews.csv) | Review scores, each linked to the review. |

What each field means, and the page each fact appears on: [gtasix.how/data/](https://gtasix.how/data/).
